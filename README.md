#refactoring code using Black,isort,flask8
1) Initialize the refactoring of code by installing black,isort,flask8
    pip install black
    pip install isort
    pip install flask8
3) Then format the code using black(Black is an opinionated code formatter that automatically reformats your Python code to adhere to PEP 8.)
   black nonformatedcode.py
4) isort organizes your import statements according to PEP 8 guidelines
   isort nonformatedcode.py
5) flake8 checks your code for style violations, errors, and potential bugs. To use flake8:
   flake8 nonformatedcode.py
